패킷 형식 정리

패킷 형식 (방 소켓 전용, 헤더 없음, 16바이트 고정)
  timeMs (4) : 게임 시작 후 경과 시간(ms), 클라이언트 기준
  event  (1) : 무슨 일이 일어났는지
  arg8   (1) : 추가 값 1
  arg16  (2) : 추가 값 2
  arg32  (4) : 추가 값 3
  score  (4) : 보낸 사람의 현재 총점
  -> recv() 로 받음

클라이언트 -> 서버 -> 상대 클라이언트 (게임 이벤트, 서버는 그대로 중계)
  1. BLOCK_HIT    : Silver 블록이 맞았지만 안 깨짐
                    arg16 = 블록 번호, arg32 = 남은 내구도
  2. BLOCK_BROKEN : 블록 파괴
                    arg16 = 블록 번호, arg32 = 얻은 점수
  3. ITEM_GET     : 아이템 캡슐 획득
                    arg8 = 아이템 종류
  4. ITEM_END     : 아이템 효과 끝남
                    arg8 = 아이템 종류
  5. BALL_LOST    : 공을 모두 놓쳐 리스폰 대기 시작
                    arg32 = 대기 시간(ms)
  6. RESPAWN      : 새 공 지급 (Player 아이템이면 대기 없이 바로)
                    인자 없음
  7. STAGE_CLEAR  : 스테이지 클리어 (3이면 모든 스테이지 완료)
                    arg8 = 스테이지 번호, arg16 = 남은 공 수, arg32 = 보너스 점수
  8. STAGE_START  : 다음 스테이지 시작
                    arg8 = 스테이지 번호
  * 모든 이벤트에 score(현재 총점)를 같이 보냄

클라이언트 -> 서버 (연결용)
  9. JOIN	: 방 소켓 연결 직후 첫 패킷
           	arg32 = 토큰 
		or
		플레이어 번호 + 방 번호	

서버 -> 클라이언트 (서버가 직접 만들어 보냄)
  10. TIME_SYNC   : 5초마다 화면 타이머를 서버 시간에 맞춤
                    arg16 = 남은 시간(초)
  11. GAME_END    : 시간 종료(유예 1초 후) / 둘 다 스테이지 3 클리어 / 상대 나감
                    arg8 = 결과(0 패배, 1 승리, 2 무승부)
                    arg16 = 종료 사유, arg32 = 상대 점수, score = 내 점수
  12. OPP_LEFT    : 게임 중 상대 연결 끊김 (바로 뒤에 GAME_END 보냄)
                    인자 없음
